# Tests

This directory will contain reference testing infrastructure, examples, and reusable test support.

## Planned Areas

- unit
- integration
- system / end-to-end
- acceptance
- accessibility
- security
- data-validation
- CI-oriented smoke tests

Reference tests should support teaching and reproducibility without giving away every student solution.

Where possible, test suites should produce machine-readable and human-readable results suitable for continuous testing.

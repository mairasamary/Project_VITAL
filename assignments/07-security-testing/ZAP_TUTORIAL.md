# Passive security analysis with ZAP
Install ZAP from https://www.zaproxy.org/download/ and record its version. Start your isolated local OpenEMR with synthetic data. In ZAP choose Safe mode, use Manual Explore to launch its configured browser, and enter only your local OpenEMR URL. Do not select Automated Scan, active scan, spider or AJAX spider. Avoid unrelated browsing in the proxied browser. Log in using approved test accounts and perform ordinary workflow interactions. Wait for the passive scan queue to finish. Review alerts, affected response, confidence and context; do not assume an alert is an exploitable vulnerability. Manually investigate three observations using ordinary browser interactions or DevTools. If there are fewer alerts, examine relevant passing header/cookie checks. Export only sanitized summaries, never raw session histories, request bodies or tokens. Close the proxied browser and ZAP after testing. Local HTTP may explain absent Secure/HSTS; do not generalize to production. If the browser cannot connect, verify the local port and proxy setup; ask the instructor before changing TLS or security settings.

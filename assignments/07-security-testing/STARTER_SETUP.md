# Starter setup
Use Python 3.11+ and Bash for the supplied fixture. From the project root run bash environment/security-testing/run_stage1_validation.sh. For team repositories, copy the entire environment/security-testing directory and .github/workflows/security-tests.yml from the approved course starter. Keep fixture and live tests separate. For live browser automation use the Playwright installation instructions at https://playwright.dev/docs/intro; pin dependencies and commit the lockfile. Use environment variables for approved local credentials, never defaults. Restrict the target to loopback and use synthetic records. Start with a fresh browser context per role; verify the expected identity and a positive authorized control before evaluating denial. Assert absence of protected content as well as the expected denial behavior. Do not treat any redirect or HTTP 200 alone as proof. Document selectors from your actual workflow and clean up synthetic changes. The supplied Python baseline scripts are optional observations, not assertions; they disable TLS certificate validation and must not be used to infer TLS security. Use DevTools/ZAP instead if uncertain.

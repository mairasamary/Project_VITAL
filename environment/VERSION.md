# Reference Environment Versions

Project VITAL reference baseline:

| Component | Version |
|---|---|
| OpenEMR | 8.2.0 |
| MariaDB | 11.8.8 |
| Docker Compose | Compose v2 recommended |

## Reproducibility policy

The course should freeze these versions for a semester.

Do not replace the OpenEMR image with `latest`, `next`, `dev`, or another floating tag during a course offering.

Before each new course offering, the instructor should review upstream security fixes and decide whether to update the Project VITAL baseline. Any update should be tested before student distribution.

# Instructor Materials

This directory contains instructor-facing guidance for adopting and teaching Project VITAL.

## Intended Contents

- course integration guide;
- suggested 10–12 week schedule;
- setup instructions;
- classroom activity notes;
- assignment release guidance;
- expected student difficulties;
- suggested checkpoints;
- grading guidance;
- solution notes where appropriate;
- privacy and FERPA considerations;
- safe security-testing guidance;
- options for adapting the kit to another System Under Test.

## Teaching Model

The project is intended to combine:

- guided in-class exploration;
- team-based project work;
- out-of-class implementation and analysis;
- individual accountability where desired.

The default team size is **3–4 students**.

Instructors are encouraged to grade the quality of students' testing process, reasoning, evidence, reproducibility, and interpretation rather than the raw number of defects discovered.
